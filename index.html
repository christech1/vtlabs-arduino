VTLabs Training Kits — Arduino Boards Manager

  1. Install Arduino IDE 2.3.3 or newer.
  2. File → Preferences → Additional boards manager URLs, add:
    https://christech1.github.io/vtlabs-arduino/package_vtlabs_index.json
  3. Boards Manager: install esp32 by Espressif Systems 3.3.x, then VTLabs Training Kits.
  4. Tools → Board → VTLabs Training Kits → your kit.

Latest version: 0.2.0. Source and releases: github.com/christech1/vtlabs-arduino
